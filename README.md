# Landing SOTEC

Landing de SOTEC: seguridad electrónica, telecomunicaciones, energías renovables y automatización.

Sitio publicado: https://carforck.github.io/Landing-Sotec/

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:5180
```

## Publicar en GitHub Pages

```bash
npm run deploy   # compila y sube dist/ a la rama gh-pages
```

## Contenido

Todo el texto, servicios, galería y ciudades del mapa están en `src/data.js`.
Las filas marcadas con `VALIDAR` deben confirmarse con SOTEC antes de usar el sitio en producción
(ciudades del mapa de presencia, segundo teléfono, detalle de servicios y preguntas frecuentes).

Las imágenes están en `public/img/` en formato WebP.
